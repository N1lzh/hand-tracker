 # Hand Tracker

 A browser-based hand tracking demo built with React, TypeScript, and MediaPipe.
 It uses your webcam to detect up to two hands in real time and draws their
 landmarks over the live video preview.

 ## Run locally

 ```bash
 npm install
 npm run dev
 ```

 Open the local Vite URL in a camera-enabled browser and choose **Request Camera
 Access**. Camera permissions are required for tracking.

 ## Stack

 - React and TypeScript
 - Vite
 - [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js)
